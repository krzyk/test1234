# Kody ASCII

**ASCII** (*American Standard Code for Information Interchange*) to standard kodowania, który przypisuje liczbowe wartości (kody) literom, cyfrom, znakom specjalnym oraz kontrolnym w celu umożliwienia komunikacji między komputerami i urządzeniami elektronicznymi.

1. **Zakres kodów**:

   - ASCII jest 7-bitowym systemem kodowania, co oznacza, że może reprezentować 128 różnych znaków (od 0 do 127).
   - Kod obejmuje:
     - **Znaki alfanumeryczne**: litery (A-Z, a-z), cyfry (0-9).
     - **Znaki specjalne**: np. `@`, `#`, `$`, `%`, `*`, `&`, itp.
     - **Znaki kontrolne**: np. `NULL` (0), `BEL` (7, dźwięk dzwonka), `ESC` (27, znak ucieczki), używane do sterowania urządzeniami.
2. **Przykładowe kody ASCII**:

   - `A` = 65
   - `a` = 97
   - `0` = 48
   - Spacja = 32
   - Enter (LF, Line Feed) = 10
3. **Cel**:

   - ASCII powstało w latach 60. XX wieku jako standard pozwalający na reprezentowanie tekstu w formie zrozumiałej dla komputerów oraz wymianę informacji między różnymi systemami komputerowymi.
   - W późniejszych latach wprowadzono rozszerzenia, takie jak **ASCII rozszerzone** (8-bitowe), które dodają dodatkowe 128 znaków (256 znaków w sumie), zawierające np. symbole narodowe (ą, ć, é) i inne znaki graficzne.

- Standard ASCII był najpopularniejszym zestawem znaków używanym w internecie do grudnia 2007, kiedy to został zastąpiony przez [UTF-8](https://pl.wikipedia.org/wiki/UTF-8 "UTF-8"). Kodowanie UTF-8 jest wstecznie kompatybilne z ASCII

   2. Wczytaj literę a następnie sprawdź, czy wczytałeś małą czy dużą literę.
   3. Wczytaj małą literę a następnie zamień ją na dużą.
   4. Policz sumę kodów ASCII liter Twojego inicjału.
   5. Zakoduj szyfrem Cezara Twój inicjał.
   6. Zamień znak '0' na 0.
