# Petla while, do-while - lista 5

0. Program wczytuje liczby i sumuje je dopóki nie zostanie wczytane zero. Która pętla będzie lepsza w tym zadaniu (while, czy do-while), dlaczego.

1 Program w pętli wczytuje podawane przez Ciebie liczby i mnoży je. Pętla działa dopóki ich iloczyn nie przekroczy 100. Następnie wypisuje iloczyn oraz liczbę wykonań pętli.

2. Program w pętli wczytuje liczby i jeśli są parzyste sumuje je. Program kończy działanie, gdy suma przekroczy 50 lub dodane zostanie 10 liczb.

3. Program wczytuje kolejno liczby całkowite oraz dodaje do siebie tylko liczby jednocyfrowe parzyste. Wczytywanie kończy się gdy suma osiągnie lub przekroczy 20 lub gdy zostanie wczytane 5 liczb. Wypisz:

- sumę liczb
- ile liczb zostało dodanych
- ile liczb zostało wczytanych.

4. Program wczytuje kolejno znaki dopóki nie zostanie podana ‘\*’, Za którym razem podano ‘\*’.

5. Na początku program wczytuje od jednego użytkownika jedna liczbę. Następnie drugi użytkownik próbuje zgadnąć jaka to jest liczba podpowiadając jednocześnie, czy liczba jest większa, czy mniejsza. Program mówi użytkownikowi za którym razem udało mu się zgadnąć.

6. Program wczytuje od użytkownika znak. Następnie użytkownik próbuje zgadnąć jaki jest jego kod ASCII. Program podpowiada, czy kod jest większy, czy mniejszy. Program mówi użytkownikowi za którym razem udało mu się zgadnąć.

7. Wypisz liczby dwucyfrowe (wszystkie) rosnąco.

8. Wypisz liczby trzycyfrowe parzyste malejąco.

9. Wygeneruj tablicę kodów ASCII - wypisz wszystkie znaki i odpowiadające im kody ASCII
