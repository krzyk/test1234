# Algorytmy linowe i warunkowe - lista zadań

1. Znajdź pole trapezu
2. Znajdź pole i obwód trójkąta
3. Sprawdź, czy dwie wczytane liczby są takie same
4. Wczytaj liczbę i znajdź odwrotną i przeciwną
5. Sprawdź, która z dwóch wczytanych liczb jest większa (uwzględnij liczby równe)
6. Sprawdź, czy 3 wczytane liczby są takie same (uwzględnij liczby równe)
7. Sprawdzenie, czy wczytana liczba jest parzysta
8. Sprawdzenie, czy wczytana liczba jest jednocyfrowa
<a id="yui_3_13_0_2_1472641999527_514"></a>9. Sprawdzenie czy 3 boki stworzą trójkąt
<a id="yui_3_13_0_2_1472641999527_536"></a>10. Znając 3 boki trójkąta znalezienie obwodu (uwzględnienie tego, że nie zawsze da się zbudować trójkąt) ponadto sprawdzenie, czy jest równoboczny, czy jest prostokątny
